# 설계 가정

상태: 2026-10-05, 사용자 결정(「규정 라벨은 가정으로 바꿔서 명시적으로 가자」)으로 개발 상태 기록(비공개)의 미해결 라벨 두 줄(「미검증」 운영 규정·보존·LLM 처리 조건, 「확인 필요」 가용성·복구·보존·연동·AI 실패 정책)을 이 표로 바꿨다.

**이것은 사실이 아니라 가정이다.** 기준 고객 A사는 가상의 대형 SI 회사라 실제 규정을 받을 수 없다. 각 항목은 이 프로젝트가 **어떤 값을 전제로 설계·구현했는지**를 적은 것이고, 실제 고객사가 확정한 정책으로 대체되기 전까지는 운영 적용 근거가 아니다. 고객사 정책이 다르면 해당 값만 바꾸고 「바뀌면 영향받는 곳」을 따라 고친다. 사용자가 값을 바꾸면 이 문서가 기준이다.

## 해소와 한계
- **해소된 것:** 개발 상태 기록(비공개)의 미해결 라벨 두 줄이 사라지고, 게이트의 라벨 검사(`L1`)와 완료 조건에서 이 항목들이 더는 막지 않는다.
- **해소되지 않은 것:** 위 가정은 검증된 사실이 아니다. 운영 배포 판정은 이 가정을 고객사의 확정 정책으로 대체하기 전까지 「배포 보류」다.
