## cAdvisor를 뺀 이유
설계 때 첫 실행에서 확인하기로 한 항목이다. Docker Desktop(Mac)에서 읽기 전용 호스트 마운트(`/`, `/var/run`, `/sys`, `/var/lib/docker`)로 띄우니 Docker 컨테이너 등록이 실패했고(`Cannot connect to the Docker daemon at unix:///var/run/docker.sock`), 지표는 VM 전체(`id="/"`) 하나뿐이었다. privileged로는 기동하지 않았다. Docker 소켓을 넘기면 될 수 있지만 그것은 Docker API 전체 권한이라 승인 범위 밖이다. 설계에서 정한 대로 빼고 「컨테이너 CPU 없음」으로 남긴다. 앱 CPU는 `process_cpu_usage`(JVM이 보는 2 CPU 대비), DB 컨테이너 CPU는 부하 시험 중 `tests/load/sample.sh`가 `docker stats`로 남긴다.
